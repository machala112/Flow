# CharacterLock

**Cross-platform AI video character consistency tool.** Enforces visual (face)
and audio (voice) consistency for a character across video clips generated by
*any* AI video platform (Sora, Google Flow, Kling, Runway, Pika, …) — applied
as a **post-processing** step on already-generated files. No generation APIs,
no prompt engineering, no real-time processing: batch only.

```
reference faces (5-20 imgs) ─┐
                             ├─► characterlock init ──► project/ (identity + voice embeddings)
reference voice (10-30s) ────┘

raw clips (scene1.mp4 …) ──► characterlock process ──► corrected clips (+ optional stitched final)
```

## Pipeline

1. **Identity extraction** — InsightFace (`buffalo_l`) extracts face embeddings
   from the reference images; averaged into one canonical embedding
   (`identity.npz`).
2. **Voice extraction** — speaker embedding from the reference audio
   (`voice_embedding.npy`).
3. **Per-clip face pass** — ffmpeg extracts frames → faces detected
   (InsightFace/RetinaFace) → identity-corrected with the inswapper model →
   restored/blended with GFPGAN → re-encoded with ffmpeg (original audio kept).
4. **Per-clip voice pass** — audio extracted → converted to the reference voice
   (OpenVoice, content/timing preserved) → muxed back onto the corrected video.
5. **Output** — corrected clips in `/output`, optionally concatenated into one
   video with `--stitch`.

## Requirements

- Python 3.10+
- **ffmpeg + ffprobe** (system package, must be on `PATH`)
- A GPU is strongly recommended for the face/voice models; everything falls
  back to CPU (slow — fine for short test clips).

### Install ffmpeg

| OS | Command |
|---|---|
| Ubuntu/Debian | `sudo apt install ffmpeg` |
| macOS | `brew install ffmpeg` |
| Windows | `winget install Gyan.FFmpeg` or download from gyan.dev and add to `PATH` |

### Install CharacterLock

```bash
git clone https://github.com/machala112/Flow.git
cd Flow
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Install OpenVoice (from source — no PyPI release)

```bash
git clone https://github.com/myshell-ai/OpenVoice.git
cd OpenVoice
# Python 3.10/3.11: pip install -e .
# Python 3.12: setup.py is broken (pkgutil.ImpImporter removed); instead
# add the checkout to PYTHONPATH when running CharacterLock:
export PYTHONPATH="$PWD:$PYTHONPATH"
```

### Model setup

Model weights download on first run to `~/.characterlock/models/`:

| Model | Purpose | Approx. size | Location |
|---|---|---|---|
| InsightFace `buffalo_l` | face detection + embedding | ~300 MB | `~/.insightface/models/` |
| `inswapper_128.onnx` | identity correction (face swap) | ~550 MB | `~/.insightface/models/` |
| GFPGAN v1.4 | face restoration / blending | ~350 MB | `~/.characterlock/models/gfpgan/` |
| OpenVoice V2 converter | voice conversion | ~130 MB | `~/.characterlock/models/openvoice_v2/` |

## Usage

```bash
# 1. Register the character: reference faces + reference voice
characterlock init --refs ./ref_faces/ --voice ./ref_voice.wav --project myshow

# 2. Correct a folder of generated clips
characterlock process --project myshow --input ./raw_clips/ --output ./final/

# ...or stitch everything into one final video
characterlock process --project myshow --input ./raw_clips/ --output ./final/ --stitch

# ...or skip GFPGAN restoration for speed (more swap artifacts)
characterlock process --project myshow --input ./raw_clips/ --output ./final/ --no-restore
```

## Project layout

```
myshow/
  project.json          # refs dir, voice path, created_at
  identity.npz          # canonical face embedding
  voice_embedding.npy   # speaker embedding
```

## Verified

End-to-end runs on 2026-09-26 (Python 3.12, CPU, ffmpeg 8.1.2):

- **Face**: 3 s test clip (512×512, 25 fps, 75 frames) — all 75/75 frames
  swapped; sampled frame similarity to canonical identity 0.85–0.86
  (vs 0.01 to the original face, −0.03 between the two identities);
  audio track preserved.
- **Voice**: same clip re-voiced toward a 19 s reference sample —
  speaker-embedding cosine(output, target) 0.88, cosine(output, source) 0.05
  (target vs source 0.11); duration, frame count and audio track preserved.
- **Restore**: GFPGAN v1.4 verified on a swapped frame (output differs from
  input; faces detected and enhanced).
- **CLI**: `init` + `process` (with `--no-restore`) verified on the test clip:
  face sim 0.89, voice cos 0.89.
- **Tests**: 8/8 pytest pass.

## Ethical use

This tool corrects identity consistency for characters you own or have rights
to (your own AI-generated actors, licensed likenesses). Do not use it to
impersonate real people without consent.
